# Contributing

Thank you for taking an interest in Temno.

## Issues are open

Bug reports and feature requests are welcome as [issues](https://github.com/temno-io/temno/issues). For a bug, include:

- the Temno version line from **About**, which says "Built from source" and its commit when you built it;
- your Windows version and graphics card;
- what you did, what you expected, and what happened instead;
- the crash log, if Temno crashed. It is `logs\crash.log` in `%LOCALAPPDATA%\Temno`, for the
  installed app and for a source build alike, or in `%LOCALAPPDATA%\Temno-Dev` for a development
  build. Remove anything personal before you attach it.

Security problems go to security@temno.io instead; see [SECURITY.md](SECURITY.md).

## Pull requests: not yet

Temno is developed in a private repository and exported here at each release, one commit per
version. A pull request opened here cannot be merged as it stands, so for now we close pull requests
with a note pointing to issues. We will accept them once there is a scripted path that carries a
change into the development repository with its author's credit. If you have a fix, an issue that
describes it, or a link to your branch, is the best way to get it in today.

You are free to fork and change Temno under the [GNU General Public License, version 3](LICENSE).
The licence covers the code, not the Temno name or logo; see [TRADEMARKS.md](TRADEMARKS.md) before
you distribute a modified build.
